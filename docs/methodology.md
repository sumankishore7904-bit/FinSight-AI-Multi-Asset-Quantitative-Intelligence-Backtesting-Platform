# FinSight AI — Financial Analysis Methodology

## 1. Purpose

This document describes the financial calculations used by FinSight AI.

The analysis layer converts cleaned historical market data into quantitative metrics that can be used by:

- Frontend
- Risk analysis
- Indicator analysis
- Multi-asset comparison
- Quantitative intelligence
- AI explanation

The calculations are descriptive of historical data and are not guarantees of future performance.
